# 验证结果说明

验证器会显示汇总状态和逐项检查结果。判断结果时，应同时查看二者。

| 界面状态 | 含义 | 建议 |
| --- | --- | --- |
| 验证通过 | 所有必要检查均通过，且没有已知警告 | 可以依据当前公开证明核对抽奖结果 |
| 通过（有警告） | 可复算结果通过，但吊销检查使用了 CRL 回退、receipt 省略了 RFC 3161 `accuracy`，或缺少其他可验证的历史证据 | 阅读警告项，并结合独立归档材料判断 |
| 验证未通过 | 至少一项完整性、算法、归档或 drand 检查不一致 | 不要将结果视为可信抽奖结果 |
| 错误提示 | 公开证明无法读取或解析、请求超时，或版本及算法不受支持 | 核对输入和网络状态后重试；不要将其误认为验证通过 |

逐项检查中的 `✓` 表示通过，`!` 表示警告，`×` 表示失败。drand relay 暂时不可用时无法完成信标签名检查，页面会显示失败或错误，而不会降级为完整通过。验证器只接受带不可变归档登记的 protocol v2 proof；v1、缺少归档或未知版本会直接失败。

这些状态只能说明公开材料之间是否一致，不能证明主站在生成候选快照前没有漏记或错误筛选用户。详细边界见[快照承诺与归档](archival.md)。
